[Hermes Agent](https://github.com/NousResearch/hermes-agent) by Nous Research, packaged for VibePod.

## Image

- Built on the official `nousresearch/hermes-agent` image, pinned to the upstream release
- Runs as your host user through `USER_UID`/`USER_GID` mapping
- Seeds a shared skills directory on start
- `hermes` and `hermes-acp` on `PATH`
